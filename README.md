# chinese-double-pinyin-diceware

A wordlist for building passphrases you can memorize, aimed at people who read
Chinese. Pick seven words, type them in Ziranma double-pinyin, and you get 28
letters.

There are 8173 words. Each is two Chinese characters, which in double-pinyin
is exactly four letters. Seven words give 28 letters and about 91 bits.

## Usage

    python tools/pick-passphrase.py

That prints three candidate passphrases. Pick one you can picture, memorize the
words, and type them out.

    python tools/pick-passphrase.py -n 8       # 8 words per candidate instead of 7
    python tools/pick-passphrase.py -p 4096    # draw only from the 4096 most common words
    python tools/pick-passphrase.py -g 5       # print 5 candidates instead of 3
    python tools/pick-passphrase.py --show-codes

`-n` sets how many words each candidate contains, `-p` how large a pool to draw
from, `-g` how many candidates to print. The first two change the entropy, and
the script prints the resulting figure before the candidates.

    python tools/entropy.py                   # entropy, collisions accounted for
    python tools/audit.py                     # structure, readings, entropy formula
    python tools/make-wordlist-cryptogun.py   # rebuild the wordlist

Two verification scripts need extra data. Run `python tools/fetch-data.py` to
download it.

## Notes

Every word is two characters, so every code is four letters. Seven of them
concatenate into 28 letters that split only one way, which is why no separator
is needed and why two different word sequences can never produce the same
string.

Readings come from the pinyin column of the upstream wordlist. About twenty
entries there are mislabelled. Each correction is listed in
`tools/make-wordlist-cryptogun.py` with its reason.

Tones are left out on purpose. Adding them makes the output about half again as
long and buys roughly 0.002 bits, which is nothing. The costs are elsewhere.
Tones force a rule that has to be judged by hand on every single word: words
with more than one reading get no tone. No machine-readable source says which
words those are, since the national standard covers only about 800 entries and
the dictionary is not available in machine-readable form. Light tones then need
a rule of their own. A mistyped tone locks you out. And the tone data itself
comes with strings attached: the two usable sources are either share-alike
licensed or measurably wrong.

The wordlists shipped here sidestep all of it by keeping only words whose
reading is unambiguous once tone is dropped.

The wordlist is sorted by how common each word is, most common first. That is
what `-p 4096` relies on.

One pair of words shares a code with another, both being homophones. It costs
about 0.0002 bits and does not hurt recall, since either word produces the same
string.

Eighteen words were dropped for having two readings that differ in their
consonants and vowels, not just their tone. Those cannot be pinned down by
picking a reading, so they are gone rather than guessed at. They are listed in
the generator with the reason for each.

An earlier version drew on a second upstream list and dropped it. That list
builds its pinyin into a prefix code, which pushes out a large share of common
words. Our codes are fixed-length, so a prefix code buys nothing.

给中文使用者用的 Diceware 词表。选七个词，用自然码双拼打出来，得到 28 个字母。

词表有 8173 个词，每个词都是两个汉字，双拼正好四个字母。七个词就是 28 个字母，约 91 bit。

## 用法

    python tools/pick-passphrase.py

会打印三组候选。挑一组能想出画面的，把词记住，然后打出来。

    python tools/pick-passphrase.py -n 8       # 每组 8 个词，默认是 7
    python tools/pick-passphrase.py -p 4096    # 只从最常用的 4096 个词里抽
    python tools/pick-passphrase.py -g 5       # 打印 5 组候选，默认是 3

`-n` 决定每组几个词，`-p` 决定从多大的词池里抽，`-g` 决定打印几组。前两个会改变熵，脚本会在候选之前把算出的熵打出来。

    python tools/entropy.py                   # 熵，已扣除碰撞
    python tools/audit.py                     # 检查结构、读音和熵公式
    python tools/make-wordlist-cryptogun.py   # 重新生成词表

有两个核验脚本需要额外数据，用 `python tools/fetch-data.py` 下载。

## 说明

每个词都是两个汉字，所以每个码都是四个字母。七个码拼起来是 28 个字母，切法只有一种，因此不需要分隔符，也不会出现两个词序列拼出同一串的情况。

读音取自上游词表自带的拼音列。那里有二十来处标错了，每一处的修正都写在
`tools/make-wordlist-cryptogun.py` 里，附了理由。

不加声调是故意的。加了之后输出长出大约一半，熵只多 0.002 bit 左右，等于没有。
代价在别处。加声调要带进一条每个词都得手动判断的规则：多音词不加声调。哪些词算多音词没有机读依据，国家标准只覆盖八百来条异读词，词典又没有机读版。轻声还得另立一条规则。声调打错就打不开库。调号本身的数据也有包袱：能用的两个来源，一个是相同方式共享许可，一个实测读音不准。

仓库里的词表只保留去掉声调后读音唯一的词，把这些一次性绕开。

词表按词频排序，最常用的在前，`-p 4096` 就是靠这个。

有一对词同音同码。损失约 0.0002 bit，不影响记忆，写成哪个都得到同一串。

另有十八个词被剔除，它们的两个读音不只是声调不同，声母韵母也不同。这种词没法靠选定读音来定下来，只能不要。每一条的理由都写在生成脚本里。

早先还评估过另一份上游词表，放弃了。那份词表的拼音构成前缀码，代价是挤掉很多常用词。我们的码是定长的，用不上前缀码。
