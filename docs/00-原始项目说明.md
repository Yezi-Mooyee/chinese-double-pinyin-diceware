# 00 项目说明

为密码管理器数据库生成一个**只靠记忆就能复现**的根密码。做法是从中文词表里随机选词，人工转成自然码双拼，得到一串短字母。

## 产物

| 文件 | 词数 | 说明 |
|---|---|---|
| `wordlist-shuangpin-cg.txt` | 8173 | 主用：`中文词` + TAB + 双拼码，每码固定 4 字母 |
| `wordlist-zh-cg.txt` | 8173 | 纯中文词表，每行一个词，UTF-8 无 BOM |

## 方案要点

- 词表 8173 词，全部是双字词，每词 log₂8173 ≈ 12.997 bit
- 7 个词 = 90.98 bit，输出 28 个小写字母
- 每字双拼恰好 2 个字母，双字词恰好 4 个，于是全表构成**定长码**
- 定长码没有词边界歧义，既不需要分隔符，也不需要前缀码
- 实测 8173 个双拼码只有 1 组重复（同音词）
- 自然码与词表都是公开信息，唯一的秘密是选了哪 7 个词

关于定长码：它对安全性的贡献接近于零，只是达成「唯一可解码」的一种手段，加分隔符同样能做到。它的实际价值是输出最短、长度固定。不要为维持定长去牺牲别的性质。

## 排除的方案

| 方案 | 原因 |
|---|---|
| 英文 diceware / EFF 词表 | 非英语母语者词汇量不足，生词多，记住词之外还得记拼写 |
| 单字词表 | 现代汉语读音退化，单字不独立成词，不是现代人的记忆单位 |
| 加声调 | 熵只多约 +0.002 bit，输出却长一半；且要引入「多音词不加声调」这条依赖无机读判据的条件规则。见 `06` 第二节 |
| 把根密码写在纸上 | 防不住能接触住所的人 |
| 提示纸 | 提示无法把随机密码的候选缩到一个，对完全遗忘无效 |
| 延长闲置自动锁定时长 | 解锁状态下浏览器集成等全部可用，延长等于让库长期处于可用状态 |
| 依赖 Windows Hello PIN 作为主要解锁 | PIN 是共享凭据，作用域覆盖整个系统，一次泄露影响面过大 |
| 依赖「攻击者猜不到规则」 | 规则与词表公开无害，不作为防线 |
